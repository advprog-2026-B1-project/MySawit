# MySawit
Short startup guide for a fresh clone.

## Prerequisites
- Docker Desktop with Docker Compose
- Java 21
- Node.js and npm

## 1. Clone the repository
```bash
git clone <repo-url>
cd MySawit
```

## 2. Create the backend env file
Create a `.env` file in the repository root with the database and storage values used by the backend:
```properties
DB_URL=jdbc:postgresql://localhost:5432/mysawit
DB_USERNAME=mysawit
DB_PASSWORD=penyakitsawitgila
SUPABASE_URL=...
SUPABASE_KEY=...
SUPABASE_BUCKET=...
```

## 3. Start the database and monitoring stack
```bash
docker compose up -d
```

This starts PostgreSQL, Prometheus, and Grafana.

- PostgreSQL: `localhost:5432`
- Prometheus: `http://localhost:9090`
- Grafana: `http://localhost:3001` (`admin` / `admin123`)

If Prometheus does not show backend metrics, check `prometheus/prometheus.yml`. The scrape target should point to `host.docker.internal:8080` so the container can reach the backend on your machine.

## 4. Start the backend
Open a new terminal in the `backend` directory and run:
```powershell
cd backend
.\gradlew.bat bootRun
```

The backend runs on `http://localhost:8080`.

## 5. Start the frontend
Open another terminal in the `frontend` directory and run:
```bash
cd frontend
npm install
npm run dev
```

The frontend runs on `http://localhost:3000`.

## 6. Access Monitoring Tools

Once the backend and Docker containers are running, you can access the following monitoring tools:

- **Spring Boot Actuator (Raw Metrics)**: [http://localhost:8080/actuator/prometheus](http://localhost:8080/actuator/prometheus) - Displays raw metric data generated by the backend.
- **Prometheus (Metrics Server)**: [http://localhost:9090](http://localhost:9090) - The server that scrapes and stores metrics from the backend.
- **Grafana (Dashboards)**: [http://localhost:3001](http://localhost:3001) - The visualization tool for your metrics.

### Configuring Grafana

To visualize your metrics in Grafana, you need to connect it to Prometheus:

1. Open **[Grafana](http://localhost:3001)** and sign in with the default credentials:
   - **Username**: `admin`
   - **Password**: `admin123`
2. Navigate to **Connections** > **Data sources** > **Add data source**.
3. Select **Prometheus** from the list.
4. Set the **Prometheus server URL** to `http://prometheus:9090`.
5. Scroll down and click **Save & test** to verify the connection.

### Viewing Data & Dashboards

Once the data source is connected, you can build your own dashboards or import a pre-built one for Spring Boot:

1. In Grafana, click the **+ (Plus)** icon in the sidebar (or navigate to **Dashboards**) and select **Import**.
2. To use a popular community dashboard for Spring Boot (like JVM Micrometer), enter the ID **`4701`** or **`19004`** in the "Import via grafana.com" field.
3. Click **Load**.
4. In the options, select your **Prometheus** data source from the dropdown and click **Import**.
5. **Important**: Once the dashboard loads, look at the dropdowns at the very top. Set **`application`** to `MySawit` and select **`backend:8080`** in the **`instance`** dropdown. If these are not selected, the panels will show "N/A".

To stop everything:
```bash
docker compose down
```
